Build on Windows (short)
------------------------
1. Extract zip
2. Place official cores:
   tlc-link-main\src-tauri\binaries\sing-box\sing-box.exe
   tlc-link-main\src-tauri\binaries\xray\xray.exe
3. powershell -File tlc-link-main\scripts\fetch-vendor.ps1
4. tlc-link-main\BUILD-WINDOWS.bat
5. Output: tlc-link-main\dist\TLC-LINK-Portable.zip
